# 🎉 AI Event Planner with Smart Scheduling

An intelligent event planning platform with AI-powered assistance, task management, and smart scheduling capabilities. Built with **Flask**, **MongoDB**, and **AI Assistant (EVE)**.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🤖 **AI Assistant (EVE)** | Smart event planning guidance - timing, venue, budget, catering |
| 📅 **Event Management** | Create, view, and delete events with date, time, attendees |
| ✅ **Task Management** | Add tasks with High/Medium/Low priorities |
| 📊 **Dashboard Analytics** | Real-time statistics - total events, upcoming, pending tasks |
| 🔐 **Secure Authentication** | OTP verification with bcrypt password hashing |
| 📱 **Responsive Design** | Works on all devices (Mobile, Tablet, Desktop) |
| 💡 **Event Planning Tips** | Smart tips for budgeting, venue selection, timeline |

---

## 🛠️ Tech Stack

- **Backend:** Python Flask
- **Database:** MongoDB
- **Frontend:** HTML, CSS, JavaScript
- **Authentication:** Bcrypt, OTP
- **Icons:** Font Awesome
- **Fonts:** Google Fonts (Inter)
